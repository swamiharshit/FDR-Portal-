# AICTE FDR Security Deposit  Portal
Video link - https://drive.google.com/drive/folders/1ZhLS2i_iOI_G8D4dEkGD_I1bsTVxM7Us?usp=sharing


A centralized web-based platform designed to digitize and streamline the management of Fixed Deposit Receipts (FDRs) submitted by educational institutions for AICTE-related security deposit requirements.

## Overview

The AICTE FDR Security Deposit Portal provides a structured digital workflow for institutions to submit FDR details and supporting documents, while enabling authorized officers to review, scrutinize, verify, and process submissions.

The platform aims to improve transparency, document accessibility, workflow management, and accountability through role-based access control.

### Key Features

- Institution Dashboard: Create and manage FDR submissions.
- FDR Document Upload: Upload and securely store FDR PDF documents.
- Scrutiny Workflow: Enable scrutiny officers to review submitted FDR records.
- Bank Verification: Allow verification officers to record verification outcomes and supporting evidence.
- Role-Based Access Control: Separate access for institutions, scrutiny officers, verification officers, approving authorities, administrators, and auditors.
- Status Tracking: Track FDRs through different stages of the workflow.
- Audit Logging: Maintain records of important system activities.
- Centralized Database: Store FDR records and related information securely.

## Technology Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js, TypeScript
- Database: PostgreSQL (Neon)
- ORM: Prisma
- Authentication: JWT-based authentication
- Document Handling: Multer and PDF file storage

## Project Objective

To develop a secure, transparent, and efficient digital system for managing FDR submissions and their verification lifecycle, reducing manual paperwork and improving coordination between institutions and authorized officers.

## Project Status

Academic project / prototype under development. Some workflows and integrations may require further implementation and testing.
